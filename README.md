# VisualizeAgenticDev

Visual, interactive training material for agentic development concepts.

- [`harness-site/`](harness-site/): "Inside the Harness", an offline explorable-explanation site. See its README to run it.
- [`course/`](course/): the written course, "What Is a Harness?", which is the content source.
- [`docs/BUILD_SPEC.md`](docs/BUILD_SPEC.md): the build spec (v2).
- [`docs/AGENT_PLAYBOOK.md`](docs/AGENT_PLAYBOOK.md): how to add lessons in the same style; written for coding agents.

**Preview:** https://mmorrisj.github.io/VisualizeAgenticDev/ (published from `main` by `.github/workflows/pages.yml`).
